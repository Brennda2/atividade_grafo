# Busca em Largura Padrão e Busca em Largura
Projeto desenvolvido em Python utilizando lista de adjacência para representação de grafos, com implementação de funcionalidades de manipulação de vértices e arestas, Busca em Largura Padrão e Busca em Largura para encontrar o menor caminho entre dois vértices.
